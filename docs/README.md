# Agent Memory 方案设计

当前实施优先级以 [V1交付收敛计划](29-V1交付收敛计划.md) 为准：修复阻塞、固定配置、验收闭环和封版。下方早期架构与研究文档作为历史设计依据，不能视为全部已启用或本版待实现范围。

已选路线：**基于 mem0 TypeScript 开源内核进行源码级改造**，采用三层证据记忆、时序与生命周期管理、混合检索及三仓库架构。

复用 mem0 的模型适配、批量抽取及检索代码，重构其顶层编排和存储事务，新增赛题需要的状态与证据能力。服务只返回证据，固定 Answer/Judge 留在独立评测端。
