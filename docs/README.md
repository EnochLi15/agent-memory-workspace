# Agent Memory 文档

当前实施优先级以 [V1交付收敛计划](29-V1交付收敛计划.md) 为准：修复阻塞、固定配置、验收闭环和封版。下方早期架构与研究文档作为历史设计依据，不能视为全部已启用或本版待实现范围。

Agent Memory 是独立部署的证据记忆服务，采用原文证据、原子事实与状态变更记录，统一管理写入、生命周期、检索和原子提交。服务只返回证据，固定 Answer/Judge 留在独立评测端。

当前目录按职责组织：

```text
service/src/              HTTP、写入准备、生命周期、存储与检索编排
service/src/text/         实体抽取与词法归一化
service/src/retrieval/    检索评分组件
service/baseline/         固定版本对照及等价性验证
service/upstream/         来源清单与 reference/ 许可留档
eval/                    独立 HTTP 评测
configs/、scripts/       配置与工作区编排
docs/、reports/          使用设计文档与验证证据
```

启动与目录入口见 [工作区 README](../README.md) 和 [服务 README](../service/README.md)。源码复用、重构边界及许可见 [来源说明](../service/UPSTREAM.md)；初期审查过程保留在第 05 号文档中。
