## 当前重要发现

网关非流式长抽取被远端断连；流式接收修复了这类问题。应用仍等待完整 JSON 和来源验证，再一次事务提交。已修复“偶尔忘记吃药”误判删除、计划类型的无歧义归一化和无遗忘值操作记录的召回。抽取预留回退/向量/事务时间，记录模型用量。远端 HTTP 503 仍影响部分对照与 Answer/Judge，评测器逐次记录同 ID 重试，拒绝混合版本续跑。

dev-v1–v4 的 MemOps 适配错误复用了 question_pair_id：30 条开发记录只有 24 个唯一 ID，旧 500 条选择有 260 个唯一 ID。v5 已将 setting 和原始序号纳入题号，适配器、划分脚本与 runner 均检查唯一性。旧数据结果保留作故障记录；当前 dev-v5 的 U0/U1/U3/B0/B1/B2 对照正在运行，不宣称已完成最终保留集。

最新 5000 事实/16 并发离线测试：search p95 252.68ms，health p95 3.35ms；不代表远端模型吞吐。新的 U1 拆分保留两个方法体的字节 hash，确定性替身下的抽取提示词、去重、追加状态、检索分数和隔离行为与原版一致。
