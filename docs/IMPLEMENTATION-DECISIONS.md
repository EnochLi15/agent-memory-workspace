# 实施决策与设计差异

- 使用本机已有 Node 24.18.0 固定版本；TypeScript 7.0.2 strict、Node 内置测试运行器。计划中的 Vitest 没有成为依赖。
- 默认本地向量模型为已安装 nomic-embed-text:latest（768维），固定 digest 并实调验证，不重复安装另一 embedding。
- 远端结构化抽取使用 SSE 流接收，解决实测长请求被网关关闭的问题；对外 add 仍在事务完成后一次返回。
- 个别来源引文被模型改写时，修复无歧义的索引/空白差异；再次失败只保留有真实来源的事实与操作，并按生命周期限制原文补召回。未验证的破坏性操作仍不能提交。
- 同时间冲突显式保留；迟到旧事实不覆盖最新值；明确纠错与历史状态切换分开。
- 公开 MemOps 的外层 timestamp 为排序合成值，适配器显式标记其性质；不能当作用户真实事件日期。LoCoMo 保留原始 Session time。
- 返回包包含真实来源上下文及角色，用于校验抽取摘要中的主体/否定；来源携带失效或删除片段时不回传完整原文。
- Qwen3:14b Q4_K_M 在本机运行 refined Judge 的正例、反例、时间粒度用例。权重量化与上下文8192不是正式平台同等环境的证明。
- Docker Desktop 的镜像站解析停滞时，通过宿主机下载官方 Node OCI blob、逐个校验 digest 后加载镜像；没有修改全局 Docker 镜像源。
- U0原样上游副本与主候选的合成生命周期对比，发现原版返回过期城市与已要求遗忘的编号，而候选过滤它们并保留经理姓名。此结果不是公开基准准确率优势证明。
- 工程已实现独立三仓库与本地 bare 镜像交付，不需要先发布到外部托管平台。

完整官方评分配置缺口仍按原设计记录；公共保留集、消融、最终版本复核完成前不宣称完整交付。
